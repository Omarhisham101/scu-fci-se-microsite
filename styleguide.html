Style guide

One visual identity, defined once as custom properties on :root in css/site.css and used by every page.

Palette

  • --c-ink#0F1F3ABody text
  • --c-paper#FFFFFFPage background
  • --c-surface#EEF3F9Cards and hero
  • --c-brand#0B4F8ABrand: header, links, buttons
  • --c-brand-dark#083B68Hover state
  • --c-muted#3D4B63Secondary text
  • --c-accent#8A4B00Tag text

Type scale
